# Impakt Digital

Website for Impakt Digital — digital marketing, design, branding and printing in Iringa, Tanzania.

## Going live

GitHub Pages cannot host this site (it needs a running server, not just static files),
so it shows this README instead. See **[DEPLOYMENT.md](./DEPLOYMENT.md)** for the working
options: Cloudflare Workers (already configured with an automatic GitHub deploy),
Netlify/Vercel, or publishing straight from Lovable.

## Local development

```bash
npm install
npm run dev     # http://localhost:8080
npm run build   # production build into dist/
npm run preview
```
